# pages

⚠️ Эта папка необходима для корректной работы Next.js.

## Почему папка существует, хотя она пустая

В проекте используется **Feature-Sliced Design (FSD)** совместно с **Next.js App Router**.

Next.js при сборке:

- автоматически ищет папку `pages`
- если её нет в корне проекта, он может попытаться использовать `src/pages`
- это приводит к конфликту между:
  - маршрутизацией Next.js
  - архитектурой FSD

Чтобы **явно отключить Pages Router** и избежать ошибок сборки, в корне проекта создаётся пустая папка `pages`.

## Где находятся реальные страницы

Все страницы приложения находятся в FSD-структуре:

```
src/
  pages/
  features/
  entities/
  widgets/
  shared/
```

А маршруты Next.js (`app`) используются **только как слой интеграции**, который импортирует страницы из `src`.
